# CristyVPN Telegram Bot

Готовый базовый бот на Python + aiogram 3 + SQLite.

## Запуск

1. Установите Python 3.11+.
2. Создайте бота через @BotFather.
3. Скопируйте `.env.example` в `.env`.
4. Заполните `BOT_TOKEN` и `ADMIN_IDS`.
5. Добавьте бота администратором канала `@CristyVPN`, чтобы проверка подписки через get_chat_member работала.
6. Установите зависимости:

```bash
pip install -r requirements.txt
```

7. Запустите:

```bash
python bot.py
```

## Админка

Отправьте боту `/admin`.

Через неё можно добавлять ссылки для пробного периода, 30 и 90 дней, смотреть статистику, заказы, выводы и создавать промокоды.

## Важно

Оплата СБП в этой версии создаёт заказ и переводит пользователя к поддержке для ручного подтверждения. Stars также оформлены как ручное подтверждение через поддержку, потому что автоматическая Telegram Stars-оплата требует отдельного invoice/pre-checkout/SuccessfulPayment обработчика.

Для продакшена рекомендуется добавить автоматическую оплату Stars через Telegram Bot API, автоматическую выдачу подписки после `successful_payment`, полноценную обработку заявок на вывод и антифрод/лимиты.

Не храните токен бота в GitHub или в публичных сообщениях.
